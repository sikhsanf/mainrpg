# Chibi World: Lembah Asal

Game 3D chibi di browser (Three.js, tanpa asset eksternal). Buka `index.html` lewat web server / GitHub Pages dan install sebagai PWA.

Kontrol: WASD, Shift lari, Spasi lompat, 1-4 senjata, G perisai, R ganti sihir, M mastery. Controller (GameSir dll) didukung via Gamepad API.
